## 2. Test Baseline and Dependencies

- [x] 2.1 修复 Windows 上的测试套件：查明并消除 `Store` 关闭后临时目录仍被占用导致的 `EBUSY` 清理失败；生命周期测试在 Windows 上无法用 `child.kill("SIGINT")` 模拟控制台 Ctrl+C，改为平台可行的方式或明确标注平台跳过并保留实机验证项。验收：Windows 上 `bun test tests` 除明确标注的平台跳过外全部通过；不得通过放宽断言掩盖问题。结果：`EBUSY` 由 Bun 1.3.8 引起，1.4.2 下消失；引擎、传输、工作区共 19 项原仅限 macOS 的测试改用按平台选择的文件适配层并在 Windows 启用；Bun 在 Windows 上经 `expect(...).rejects` 等待时不读取文件桥输出导致挂起，改为先取得拒绝结果再做同样断言；生命周期测试在 Windows 经标准输入触发同一 SIGINT 处理。Windows 全量 82 通过、2 项 macOS 剪贴板测试跳过。
- [ ] 2.2 按第 1 组结论，把 `ink`、`react` 以精确版本加入运行时依赖，`@types/react`、`ink-testing-library` 加入开发依赖，更新 `bun.lock`；`tsconfig.json` 启用 `react-jsx` 并纳入 `src/**/*.tsx`、`tests/**/*.tsx`；`scripts/build.ts` 改用 `Bun.build` 编译，以插件把 `react-devtools-core` 解析为空实现，并关闭 `autoloadDotenv` 与 `autoloadBunfig`；开发机 Bun 版本与 `packageManager` 声明的 1.4.2 一致。验收：`bun run check` 通过，`bun run build` 四目标产物在无 Bun 的环境输出帮助和版本。进度（2026-10-14）：实现完成；`Bun.build` 编译的入口模块 `import.meta.main` 为 false，独立产物改由 `src/main.ts` 进入。Windows 上 `bun run check` 通过；windows-x64 产物在无 Bun 的 PATH 下输出帮助和版本，且不读取运行目录的 `.env`。windows-arm64 已构建，待 ARM 设备运行；macOS 两个目标需在 Mac 上编译原生模块后构建并运行。

## 3. Runtime Session and Engine

- [x] 3.1 扩展任务库：`setConfig`/`config` 的键类型增加 `queue_paused`、`clipboard_watch`；新增只读查询，返回分享的标题、输出根、扫描状态、取消标记与汇总计数，以及按分享列出文件的 ID、相对路径、大小、状态、重试次数、取消标记、最近错误、断点字节和云端副本状态。验收：状态测试覆盖账号隔离、超出 JS 安全整数的大小、无交付记录或无副本时的默认值，以及只读连接可调用该查询。
- [x] 3.2 执行器：`Engine.step` 在现有系统暂停检查之外读取 `queue_paused`；进度事件改为 `{ type: "progress", id, bytes, size }`，每秒最多 4 次。验收：执行器测试证明用户暂停时不扫描、不转存、不下载、不回收；用户暂停与系统暂停并存时只解除其一仍不调度；进度事件字段正确且频率不超过上限。
- [x] 3.3 从 `foregroundLoop` 提取 `src/runtime/session.ts`：每次步骤使用独立中断控制器，依据 `scanning`、`saving`、`downloading` 事件跟踪当前执行项；命令队列支持 `retry`、`cancel`、`pauseQueue`、`resumeQueue`、`submitText`、`setOutputRoot`、`setClipboardWatch`，在两次步骤之间按序执行；针对当前执行项（或其所属分享）的取消和暂停先中断并等待当前步骤返回，再写任务库并唤醒调度；剪贴板监听按 `clipboard_watch` 启停；提供事件订阅。`watch` 改为使用该会话。验收：现有生命周期与接收测试语义不变且通过；新增测试覆盖命令顺序执行、取消下载中文件后断点与云端副本保留且其他文件继续、暂停后重建会话仍暂停、手动提交文本与剪贴板走同一接收规则且不与上次剪贴板内容拼接、关闭监听后不再读取剪贴板。
- [ ] 3.4 补充中断安全测试：分别在下载中途、转存提交前后、扫描翻页中和删除提交后触发步骤中断。验收：不产生重复提交，未知结果进入核对，断点与已确认状态不倒退，后续步骤能从任务库正确恢复。
- [ ] 3.5 纯文本 `watch` 进度限频：同一文件只在跨过 10% 整数倍或距上次输出满 30 秒时打印。验收：输出函数的单元测试覆盖阈值跨越、相同百分比不重复、30 秒兜底和多文件交替。

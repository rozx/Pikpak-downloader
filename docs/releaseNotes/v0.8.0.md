# PikPak Downloader v0.8.0

发布日期：2026-10-15

首个公开发布。复制 PikPak 分享文本，程序就会逐个转存其中的文件，下载、校验后放进本地目录，并在云盘空间不足时自动回收自己创建的副本。提供 Windows、macOS 与 Linux 的单文件可执行程序。

## 新功能

- **复制即下载**：在后台监听剪贴板，识别包含链接和提取码的分享文本后自动加入队列；也可以在界面里按 `a` 粘贴，粘贴框会实时提示识别到的分享数与提取码。
- **全屏终端界面**：不带参数运行即进入。启动时检查登录与下载目录；主面板按下载目录分组显示分享与文件的状态、进度、速度和剩余时间，名称前的图标表示文件在本地、云端还是两处都有；按 Enter 查看文件详情，包括失败原因与建议。
- **云盘只作中转**：逐个文件转存，下一个文件放不下时才回收已完成的副本，最旧的先回收。只删除有转存记录作为凭证的副本，删除前重新核对远端信息，不会动你自己存进云盘的文件。
- **手动释放云端副本**：选中文件或分享按 `x` 立即释放其云端副本，`X` 释放全部已完成任务的副本。已完成的任务随之从列表中删除；未完成的文件保留断点，继续时从分享重新转存。
- **多连接与多文件下载**：大于 8 MiB 的文件默认用 4 个连接分段下载，可在设置中调为 1–8；同时下载的文件数可调为 1–5，会员最多 5 个，免费账号 1 个。遇到限流时自动降低该文件的连接数。
- **断点续传与内容校验**：断网、暂停、退出或重启后从断点继续；下载完成后与 PikPak 提供的 GCID 比对，不一致不算完成。完成的文件以不覆盖的方式放进以分享标题命名的文件夹，与已有文件重名时追加后缀。
- **随时控制任务**：`p` 暂停或继续选中的文件或分享，`P` 全部暂停或全部开始，`r` 重试，`c` 取消（保留本地文件、断点和云端副本）。设置、粘贴、暂停等操作在下载进行中立即生效。
- **浏览器授权与账号页**：在 PikPak 官方页面授权，程序不接触密码；授权缺少必需权限时会提示并引导重新授权。设置页的账号页显示账号、会员、云盘容量与各项权限，可以重新授权或登出。令牌与提取码存放在系统凭据库。
- **命令行模式**：`login`、`watch`、`status`、`retry`、`cancel`、`config`、`permissions`、`logout` 等子命令供脚本与非交互场景使用；运行中仍可用 `status` 只读查看任务。

## 下载

| 平台 | 文件 |
| --- | --- |
| macOS Apple 芯片 | `pikpak-downloader-darwin-arm64` |
| macOS Intel | `pikpak-downloader-darwin-x64` |
| Windows x64 | `pikpak-downloader-windows-x64.exe` |
| Windows arm64 | `pikpak-downloader-windows-arm64.exe` |
| Linux x64（glibc） | `pikpak-downloader-linux-x64` |
| Linux arm64（glibc） | `pikpak-downloader-linux-arm64` |

`SHA256SUMS.txt` 列出各文件的校验和。macOS 与 Linux 下载后需先 `chmod +x`；Linux 需要 glibc 2.28 及以上，依赖见 README 的“平台说明”。

## 升级说明

首个公开发布，直接运行即可。用过开发版本的任务库会在启动时自动迁移到当前结构，迁移前先生成一致性备份。

## 已知问题与待验收

- 实际运行验证集中在 Windows x64（Windows Terminal）：登录、剪贴板接收、下载、暂停、恢复与释放。macOS 两个目标、Windows arm64、Windows 传统控制台、Linux 桌面与 Linux arm64 尚未在实机上完整演练；Linux 的测试在 x64 上通过。
- 部分故障场景（请求响应丢失后的核对、原分享失效后读取副本）只有合成测试覆盖。
- 同时下载文件数的会员上限 5、免费账号 1 来自实际使用经验，未经正式压测。

# Spec Delta

## Purpose

在全屏界面中设置同时下载的文件数，并同时显示多个文件的下载进度。

## ADDED Requirements

### Requirement: 同时下载设置与多文件进度

设置页 SHALL 提供“同时下载的文件数”选项，用 ←→ 在 1–5 之间调整并立即保存；受账号等级限制时 SHALL 同时显示配置值、实际生效值和原因。主面板 SHALL 为每个在途文件分别显示进度条、百分比、速度、剩余时间与动态图标；标题栏在有下载时 SHALL 显示在途文件数与上限，以及各文件速度之和；窗口宽度不足时 SHALL 先按现有顺序省略本地剩余与云盘，再省略合计速度。

#### Scenario: 调整同时下载的文件数
- **WHEN** 会员账号在设置页把同时下载的文件数从 1 调到 3
- **THEN** 设置立即保存并显示生效值 3；到达 1 或 5 时不能继续调整

#### Scenario: 免费账号调整
- **WHEN** 免费账号在设置页把同时下载的文件数调到 3
- **THEN** 设置页显示配置值 3、实际生效 1，并说明免费账号同时只能下载 1 个文件

#### Scenario: 多个文件同时显示进度
- **WHEN** 3 个文件正在下载
- **THEN** 3 行分别原地刷新各自的进度与速度，标题栏显示“下载中 3/3”和合计速度

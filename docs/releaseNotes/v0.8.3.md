# PikPak DL CLI v0.8.3

发布日期：2026-10-15

补全 v0.8.2 的 Windows 图标修复，功能与 v0.8.2 相同。

## 修复

- **Windows 图标在各种尺寸下正确显示**：v0.8.2 的产物中仍残留 Bun 原有的图标组，资源管理器优先读取它，结果小图标仍是 Bun 的图标，大图标是被拉伸的小图、显得模糊。v0.8.3 让所有图标组都指向本项目的图标。
- **图标更清晰**：小尺寸改用专门绘制的简化图案，每个尺寸按整像素绘制，边缘不再发虚；并补充了 Windows 在 125%–200% 显示缩放下使用的 20、40、72、96 像素尺寸。

macOS 与 Linux 的可执行文件本身无法内嵌图标，这两个平台没有变化。

## 下载

| 平台 | 文件 |
| --- | --- |
| macOS Apple 芯片 | `pikpak-dl-cli-darwin-arm64` |
| macOS Intel | `pikpak-dl-cli-darwin-x64` |
| Windows x64 | `pikpak-dl-cli-windows-x64.exe` |
| Windows arm64 | `pikpak-dl-cli-windows-arm64.exe` |
| Linux x64（glibc） | `pikpak-dl-cli-linux-x64` |
| Linux arm64（glibc） | `pikpak-dl-cli-linux-arm64` |

`SHA256SUMS.txt` 列出各文件的校验和。

## 升级说明

直接替换可执行文件即可。资源管理器按路径缓存图标，替换后若仍显示旧图标，可以把文件改名，或重启资源管理器刷新。

## 已知问题与待验收

- 图标已通过 Windows API 直接从 x64 产物读取核对（16、32、256 像素）；资源管理器中的实际显示与 Windows arm64 产物尚未实机查看。
- v0.8.1 列出的待验收项仍然有效：macOS、Windows arm64、Windows 传统控制台、Linux 桌面与 Linux arm64 尚未在实机上完整演练。

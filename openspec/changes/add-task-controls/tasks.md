# Tasks

按依赖顺序执行。来源：用户 2026-10-15 实测全屏界面后的反馈。复合任务只有实现与验收全部满足才勾选。

## 1. Immediate Commands

- [x] 1.1 会话命令分为中断类与立即类：`pauseQueue`，以及目标是当前串行步骤所处理文件或分享的 `cancel`、`pauseTask` 走现有队列并先中断步骤；其余命令进入串行 Promise 链立即执行，下载池中的目标先用 `engine.stopActive` 停下。验收：会话测试证明一个步骤运行期间，设置、粘贴、恢复、重试和针对非当前项的取消立即生效且不中断步骤；暂停队列与取消当前项仍先中断步骤再写入，且写入前不会开始新步骤。
- [x] 1.2 `FileWorkspace.open` 在打开根目录期间若分享被迁移到新目录，就按新目录重新打开，再写入根目录身份。验收：测试在打开过程中迁移分享，结果的根目录身份属于新目录。

## 2. Per-task Pause

- [ ] 2.1 任务库结构升到 5：`files.paused`、`shares.paused`；Store 提供暂停与继续（文件、分享）、全部开始（清除全部单项暂停），`nextFile` 与 `nextScan` 跳过暂停项，`fileViews`、`shareViews` 返回暂停状态。验收：迁移测试（4 → 5 先备份、失败回滚）；状态测试覆盖暂停文件、暂停分享、继续分享清除文件标记、已完成文件忽略暂停、调度跳过暂停项、取消标记不受全部开始影响。
- [ ] 2.2 会话命令 `pauseTask`、`resumeTask`、`startAll`：暂停先停下目标（下载池或串行步骤），全部开始清除队列暂停与全部单项暂停并唤醒调度。验收：会话测试覆盖暂停在途文件后其他文件继续、暂停分享停止其在途文件、继续后恢复下载、全部开始、重启后保持暂停。
- [ ] 2.3 界面：`p` 暂停或继续此项、`P` 全部暂停或全部开始，提示随状态变化；暂停项显示“⏸ 已暂停”，分享行显示“· 已暂停”。验收：帧测试覆盖按键命令、提示文字与暂停显示。

## 3. Manual Cloud Release

- [ ] 3.1 Store 与 SpaceManager：查询文件的合格副本（本工具创建、有证据、保留中、文件不在执行中）；在云端操作锁内核对、静默删除并核对结果；服务端拒绝时恢复保留中并记录被拒绝的结果；未完成文件删除后改回就绪、保留断点。验收：模拟服务测试覆盖已完成文件释放、暂停中文件释放后继续时重新转存并从断点完成、权限被拒绝时副本保留且账号不暂停、正在执行的文件被拒绝、非本工具创建的副本被拒绝；自动回收与手动释放不会同时删除同一副本。
- [ ] 3.2 会话命令 `releaseCopy`（文件或分享）与界面 `x`：确认框说明永久删除与重新转存的后果；事件区报告释放数量与空间或拒绝原因；释放后刷新云盘容量。验收：帧测试覆盖确认框（已完成与未完成两种文字）、无合格副本时的说明、确认后的命令。

# Tasks

当前交付仅为规划，以下实施任务全部未开始。按依赖顺序推进：第 1 组通过后，才能把外部接口能力作为后续业务实现的前提。各组覆盖对应规格中的场景；测试证据区分真实接口、模拟服务和实际操作系统，不用其中一种替代另一种。

## 1. Feasibility

- [ ] 1.1 验证 G1 的独立登录和权限：尝试第三方浏览器授权，不可行则验证交互式账号密码路径、会话刷新和账号身份；使用明确指定的测试资源验证定向永久删除，记录脱敏结果及可用授权路径到 `design.md` 的 G1 行。验收：不调用官方 CLI，能读取、转存、查询容量、删除指定测试 ID，且相邻非目标资源不受影响。
- [ ] 1.2 验证 G2 的分享分页、嵌套子文件转存、异步就绪及来源到副本映射；分别记录源与副本的 ID/版本，覆盖响应丢失、同名既有文件、原分享失效后账号副本读取、副本确定不存在与权限失败的区别，以及删除后容量刷新。验收：提供可复现的脱敏契约样本，证明只转存选中的子文件且未知结果不会误认或重复创建。
- [ ] 1.3 验证 G3 的内容版本、大小、摘要算法、Range 和临时下载地址刷新；覆盖同大小替换、只改名、零字节和版本中途改变。验收：在 `design.md` 明确版本标识和完整性判据，记录不能使用的弱标识及实际校验能力。
- [ ] 1.4 使用隔离验证程序检查 G4 的 macOS/Windows 稳定剪贴板快照、相同文本重复制、快速覆盖、受保护凭据、SQLite 事务、进程锁和不覆盖发布后的文件身份核对；确认 Go 及驱动依赖版本。验收：记录目标 OS/架构及实际运行结果，不能将只编译通过的目标标记为验证通过。
- [ ] 1.5 汇总 G1–G4 的通过状态、失败原因和脱敏证据，复核是否仍满足六份规格。验收：关键条件全部通过后才继续第 2 组；任一失败则明确记录阻塞并重新评审，未经决策不改为官方 CLI 依赖、整目录转存或扩大删除范围。

## 2. Runtime and State

- [ ] 2.1 建立 Go 模块、CLI 入口及平台适配边界，锁定第 1 组验证的依赖。验收：macOS 与 Windows 构建成功，发行产物能在无 Go/Python/Node 运行时的环境输出帮助和版本。
- [ ] 2.2 建立 SQLite 账号、固定目标的分享、请求版本和扫描世代、文件版本、云端副本、本地交付和操作意图记录及结构版本管理。验收：事务/唯一约束测试覆盖重复接收、持久重试预算、取消标记和未提交结果，重启不丢失已确认接收的工作。
- [ ] 2.3 实现任务库单实例互斥及写命令冲突处理。验收：两个进程不能同时执行同一队列，第二进程得到明确提示；活动实例的状态仍能只读查询，异常退出不会留下永久占用的假锁。
- [ ] 2.4 实现文件级状态与分享聚合结果、暂停原因及显式重试转换。验收：状态转换测试覆盖部分成功、自动重试耗尽、全局暂停与条件未满足的恢复，并与 `transfer-queue` 规格对应。
- [ ] 2.5 记录本机状态目录、数据库备份/结构版本策略与恢复边界。验收：旧程序拒绝写入更高结构版本；说明明确丢失任务库后不能凭名称重新接管云端副本，恢复旧备份也不能未经外部状态核对直接重放任务。

## 3. Account Sessions

- [ ] 3.1 按 G1 结果实现独立登录及必要交互，浏览器路径不可用时使用已验证的密码路径。验收：登录契约测试与一次真实登录均返回服务端身份，密码输入不回显且不出现在参数、日志或普通文件中。
- [ ] 3.2 实现两平台受保护存储、分享访问资料引用、串行令牌刷新和登出。验收：保存失败不会退回明文；刷新成功后新会话被保存；登出保留任务及文件，重新登录同账号可恢复。
- [ ] 3.3 实现权限拒绝、刷新失败及账号不匹配处理。验收：故障测试证明另一账号不能执行旧任务或删除旧副本，认证暂停期间不再提交云端写入。
- [ ] 3.4 实现不可变分享资料引用及先保存秘密、后提交任务引用的流程，核对无引用资料后再回收。验收：分别在秘密保存前后和数据库提交前后注入失败，已确认任务不丢访问资料，失败更新不覆盖原有效资料，旧扫描持有的资料不会被提前清除。
- [ ] 3.5 编写登录与重新授权说明。验收：从干净配置按说明完成登录，并能按提示处理需用户验证、权限不足、受保护存储不可用和任务访问资料丢失的情况。

## 4. Intake and Discovery

- [ ] 4.1 实现已验证分享格式的文本解析和规范化，保留精确主机/路径检查。验收：解析测试覆盖完整文本、无码分享、错误/缺失码、单独复制的码、多链接明确配对、歧义配对、相似域名和非分享内容；不跨复制事件猜测关联。
- [ ] 4.2 实现两平台稳定快照读取、变化标识去重、启动时单次接收和故障退避。验收：在读标识与读文本之间注入内容变化，系统不混配快照；相同文本重复制可触发请求，快速覆盖的漏读内容不能被虚报接收，普通剪贴板内容不落盘。
- [ ] 4.3 实现分享请求事务接收、固定输出根、版本化资料补充及按请求版本合并重扫。验收：用可控交错覆盖旧扫描结束前后补码、错误返回及进程重启，新请求不被清除；待扫描时更改配置不改变已接收分享目标，持久化失败不显示已接收成功。
- [ ] 4.4 实现多页与嵌套枚举、扫描世代及可靠文件版本去重。验收：契约测试覆盖分页循环、扫描中断、新增/更新/同大小替换/改名/远端移除及本地成果缺失，结果符合 `transfer-queue` 的增量规则。
- [ ] 4.5 文档说明支持的分享文本、缺码补充、主动重复制触发更新和失败项显式重试。验收：示例在解析测试中可运行，解释接收确认及未确认时重新复制；不将监听描述为历史剪贴板队列或后台定时监视分享更新。

## 5. Transfer and Local Delivery

- [ ] 5.1 实现按文件选择、目标磁盘预检、转存意图及 G2 确认的结果映射。验收：嵌套单文件转存契约测试不包含整个父目录，已有同名文件无法取得本工具所有权。
- [ ] 5.2 实现异步转存等待、结果未知核对及超时处理。验收：在请求已受理但响应丢失时重启，不重复提交；无法唯一确认时进入需人工处理状态，不猜测副本。
- [ ] 5.3 实现单连接下载、版本绑定的临时文件、持久化前缀检查点、有限重试、URL 刷新和 Range 续传。验收：覆盖正确 206、忽略范围的 200、错误范围、截断、过期 URL、远端版本变化和本地临时前缀被改动；仅使用可核对的检查点，不能拼接损坏内容或无限重试。
- [ ] 5.4 实现 G3 定义的校验、本地摘要和交付提交次序。验收：校验失败不赋予清理资格；覆盖目标冲突改名后的每次意图提交、正式发布及完成记录前的中断，恢复使用最新路径和文件身份，不能误认相同摘要的用户已有文件或重复发布。
- [ ] 5.5 实现稳定分享目录、跨平台名称映射、同名后缀和不覆盖发布。验收：测试覆盖新版本同名、重试复用目标、发布竞态、大小写冲突、保留名称、长路径、路径穿越及符号链接/目录联接，不写出根目录或覆盖已有文件。
- [ ] 5.6 实现按阶段选择原分享或已保存副本的恢复逻辑，以及确定副本丢失时的有界重新转存。验收：覆盖原分享失效但副本可用、副本消失而原版本仍在、原版本已更新、权限失败和结果未知；既不无故放弃可用副本，也不拼接新旧版本或重复未知转存。
- [ ] 5.7 文档说明固定分享目录、版本保留、续传、原分享失效后的恢复边界及实际校验方式。验收：一次单文件端到端运行生成可核对完成记录，说明不把只有本地摘要描述为已验证远端摘要。

## 6. Cloud Capacity and Reclamation

- [ ] 6.1 实现容量计划、单文件超过总容量判断和等待空间调度。验收：场景测试覆盖首次云盘已满、无合法候选、只有失败副本、其他较小文件可继续及全部等待；不得徒劳删除或忙循环。
- [ ] 6.2 实现回收候选筛选、完成时间排序和操作前复核。验收：候选测试覆盖非本工具文件、未完成或已取消但未交付版本、未知归属、共享副本仍有未交付引用、远端已变化/移动及本地成果后来被删除；最后一种仍保留资格，其他不合法候选被排除。
- [ ] 6.3 实现精确 ID 永久删除、操作意图与删除后容量核对。验收：失败注入覆盖响应丢失、权限拒绝、对象已不存在及容量延迟更新；无全局清空回收站或递归删除目录调用，容量足够后停止删除。
- [ ] 6.4 完成可用容量小于分享总大小的集成场景，记录回收策略和空间阻塞处理说明。验收：多文件经转存、下载、按需回收循环完成，本地成果全部保留，失败文件云端副本不被自动清理。

## 7. Terminal Workflow

- [ ] 7.1 集成 `watch --output`、配置持久化、目标固定规则和启动校验。验收：缺登录/缺目录时给出可操作提示，修改默认目录只影响新分享，已有分享增量文件保留原目标，暂停执行时有效输入仍能持久化。
- [ ] 7.2 实现 `status`、`retry` 和前台进度汇总。验收：部分失败分享显示准确计数，用户停下监听后可以重试失败项，再启动继续，成功版本不重下。
- [ ] 7.3 集成错误分类、全局暂停及条件恢复。验收：模拟认证失效、本地磁盘不足、数据库不可写、流量配额不足、限流和网络故障，均进入设计指定路径，只有云端存储不足可以触发回收。
- [ ] 7.4 实现 Ctrl+C 有界退出和启动核对顺序。验收：中断后先核对未知云端操作及未完成交付，再启动新工作；不注册常驻服务或开机启动项。
- [ ] 7.5 实现停下监听后的 `cancel <任务ID>`、分享/文件取消标记及 `retry` 恢复，按实际任务核对并解除无效目标导致的暂停。验收：取消不可恢复磁盘上的任务后其他任务可继续，旧剪贴板不能重启已取消分享；取消不删除文件、不清理未交付副本、不丢弃未知外部操作或撤销已发生交付。
- [ ] 7.6 编写 macOS/Windows 快速开始、失败恢复及清理行为说明。验收：用户可按文档完成登录、配置、复制文本、查询失败、重试、取消及退出；明确取消保留残留资源，本地交付后由用户管理，旧云端副本仍可回收。

## 8. End-to-End Acceptance

- [ ] 8.1 运行模拟服务端的完整流程与故障矩阵，覆盖六份规格之间的交互。验收：重复复制、并发补码、增量更新、发布改名中断、分批容量、分享失效后的副本恢复、跨存储提交失败及取消阻塞任务全部具有可重复通过的结果。
- [ ] 8.2 在明确指定的真实测试账号及样本上运行完整流程，复核 G1–G3 的事实与最终适配器一致。验收：下载内容及归属记录可核对，定向删除仅影响测试副本，邻近既有资源和本地成果保留。
- [ ] 8.3 在各承诺支持的 macOS/Windows OS/架构上安装发行候选并完成剪贴板、登录、下载、暂停、退出及恢复烟测。验收：记录实际运行矩阵；只编译或缺少验证环境的目标不能声明已通过。
- [ ] 8.4 核对文档、发行包和规格一致性并运行 `openspec validate add-clipboard-download-workflow --strict`。验收：真实验证限制如实记录，任务只在相应实现和验证完成后勾选，不把模拟测试或规划完成当作接口可行性已通过。

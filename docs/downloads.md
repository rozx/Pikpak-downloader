# 下载、校验与恢复

分享首次接收时固定下载根；分享目录与名称映射持久化，改变默认目录只影响新分享。名称会处理跨平台保留字、非法字符、Unicode 和大小写冲突。同名新版本与发布时出现的目标冲突会追加稳定后缀，不覆盖已有文件。

程序只取原始二进制下载地址，不使用媒体转码地址。下载采用单个连接与顺序 Range；地址刷新后重新核对副本身份、大小和 GCID。响应忽略范围时重启该未完成文件，不直接追加；错误范围、截断、版本变化和摘要不匹配不能成为完成记录。

临时文件与任务版本绑定。检查点先刷新实际前缀，再保存偏移和前缀 SHA-256；恢复重新读取并核对前缀，不信任 UI 上次显示的进度。超出检查点的尾部会丢弃；损坏的缓存从头读取。实际下载计算 GCID 并与服务端值比对，同时保存本地 SHA-256；本地 SHA-256 不等于服务端提供了同算法摘要。

正式发布前保存目标、尝试号、暂存文件身份与完整摘要；每次冲突换路径都先提交新意图。macOS 使用相对目录句柄和不覆盖重命名。恢复核对最后一次已保存路径、卷/文件身份及完整摘要，不能只因一个用户已有文件内容相同就认领成功。Windows 的对应原生句柄实现仍需实际运行验收。

已有转存副本时，恢复优先按账号内精确 ID 读取，不重新要求原分享仍可访问。只有明确的文件不存在类别才允许在有限预算内重新转存同一源版本；普通 404、权限失败和网络错误不证明副本已丢失。无法唯一确认的写入或发布保留记录并等待核对，不直接重发或扩大删除范围。

临时文件或目录被替换时保留现有资源；不要直接编辑任务数据库绕过保护。取消停止调度，不撤销已经发生的交付，也不赋予未交付副本清理资格。

# 云端空间与回收

云盘只作中转。下一份文件无法容纳时，才会考虑永久删除已完成副本；云端空间足够时不会提前清空。首先检查本地目标和可核对的剩余下载字节，再验证分享及源版本，然后制定云端容量计划。

候选必须同时满足：当前账号、本工具保存的明确创建证据、本地内容校验与发布完成、所有引用均已交付、当前远端身份/版本/名称/父目录仍与记录一致。证据包括本次请求返回的独立转存任务、精确来源映射、原分享和源文件标识、新建时序与内容指纹；单独的名称、时间或大小均不足以取得归属。

按最后一个引用的本地完成时间从旧到新处理，时间相同按远端 ID 排序。先确认合法候选合计足够，再逐个重新核对、记录删除意图并只提交精确 ID。每次删除后核对结果和实际容量，满足下一文件需要即停止。不会清空整个回收站，也不会递归删除目录。

已完成的本地成果由用户管理。后来移动、修改或删除本地文件不撤销云端副本的历史回收资格。未完成、失败、取消但尚未交付、归属不明、被改名/移动/改内容或仍有未完成引用的副本不进入自动回收。

第一次使用时云盘已满，或只有失败副本，没有可安全回收的对象时会等待空间；其他较小文件可以继续。单个文件超过账号总容量会明确失败，不为它徒劳删除。

删除响应丢失时核对同一对象，不改删其他资源。自动回收遇到权限拒绝时暂停执行；容量迟迟不更新时有限等待后显示同步等待，不把请求成功当成立即释放全部空间。流量额度、限流、认证失败和本地磁盘问题不会触发云端回收。

## 手动释放

在界面中选中文件或分享按 `x`，可以立即释放其云端副本，不必等到下一份文件需要空间。资格与自动回收相同的部分：只处理本工具创建、有归属证据、仍保留中的副本，并在删除前重新核对远端身份、名称、父目录与内容指纹；不同之处是文件可以尚未完成（排队、暂停、取消、失败或等待）。正在下载或校验的文件、正在落盘的文件、有未核对转存的文件以及非本工具创建的副本不会被释放，界面只说明原因。

确认框说明删除是永久的（不进回收站），本地文件保留。未完成文件的副本释放后，文件改回排队并保留断点；继续时按正常流程从分享重新转存，再从断点续传。分享已失效时将无法完成，需要提供新的分享资料。

手动释放与自动回收共用一把云端操作锁，不会同时为同一份副本发出删除。删除请求为静默模式：服务端明确拒绝（401 以外的 4xx，例如授权没有永久删除权限）时副本恢复为保留中、删除意图记为被拒绝，事件区显示原因，账号不会因此暂停；登录失效、网络中断等其他结果沿用上文规则，下次启动时核对。释放成功后事件区报告释放的空间并刷新云盘容量。

分批循环与上述故障路径已有合成服务测试。真实嵌套分享、复杂恢复及各平台实测仍是发布验收，不能由这些测试替代。

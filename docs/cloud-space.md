# 云端空间与回收

云盘只作中转。下一份文件无法容纳时，才会考虑永久删除已完成副本；云端空间足够时不会提前清空。首先检查本地目标和可核对的剩余下载字节，再验证分享及源版本，然后制定云端容量计划。

候选必须同时满足：当前账号、本工具保存的明确创建证据、本地内容校验与发布完成、所有引用均已交付、当前远端身份/版本/名称/父目录仍与记录一致。证据包括本次请求返回的独立转存任务、精确来源映射、原分享和源文件标识、新建时序与内容指纹；单独的名称、时间或大小均不足以取得归属。

按最后一个引用的本地完成时间从旧到新处理，时间相同按远端 ID 排序。先确认合法候选合计足够，再逐个重新核对、记录删除意图并只提交精确 ID。每次删除后核对结果和实际容量，满足下一文件需要即停止。不会清空整个回收站，也不会递归删除目录。

已完成的本地成果由用户管理。后来移动、修改或删除本地文件不撤销云端副本的历史回收资格。未完成、失败、取消但尚未交付、归属不明、被改名/移动/改内容或仍有未完成引用的副本不进入自动回收。

第一次使用时云盘已满，或只有失败副本，没有可安全回收的对象时会等待空间；其他较小文件可以继续。单个文件超过账号总容量会明确失败，不为它徒劳删除。

删除响应丢失时核对同一对象，不改删其他资源。权限拒绝暂停执行；容量迟迟不更新时有限等待后显示同步等待，不把请求成功当成立即释放全部空间。流量额度、限流、认证失败和本地磁盘问题不会触发云端回收。

分批循环与上述故障路径已有合成服务测试。真实嵌套分享、复杂恢复及各平台实测仍是发布验收，不能由这些测试替代。

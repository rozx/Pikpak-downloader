# Spec Delta

## Purpose

多个文件同时下载时，所有在途文件共享一个有上限的 CDN 连接预算。

## ADDED Requirements

### Requirement: 跨文件连接预算

所有在途文件的 CDN 下载连接合计 SHALL 不超过 8。每个文件新建连接时，并发上限 SHALL 取每文件连接数设置、该文件因限流降低后的并发，以及预算份额 `max(1, ⌊8 / 在途文件数⌋)` 中的最小值。在途文件数增加导致份额变小时，已经建立的连接 SHALL 完成当前分块，系统 MUST NOT 在该文件的连接数降到份额以下之前为它新建连接，也 MUST NOT 为腾出预算中断正在传输的连接。

#### Scenario: 两个大文件同时下载
- **WHEN** 每文件连接数为 4，两个大文件同时下载
- **THEN** 每个文件最多 4 个连接，合计不超过 8

#### Scenario: 第三个文件加入
- **WHEN** 两个文件各用 4 个连接下载时，第三个文件开始下载
- **THEN** 份额变为每个文件 2 个连接；前两个文件的现有连接完成当前分块后不再补足，三个文件合计在之后保持不超过 8

#### Scenario: 多个小文件
- **WHEN** 5 个都不超过一个分块的小文件同时下载
- **THEN** 每个文件使用 1 个连接，合计 5 个

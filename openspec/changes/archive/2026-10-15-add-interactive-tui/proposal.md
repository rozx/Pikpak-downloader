# Proposal

## Why

`watch` 目前每秒追加一行"下载进度 f_…: N%"，只显示内部 ID，看不到文件名、大小、速度和队列全貌；重试、取消必须先停止监听再执行另一个命令。2026-10-14 在 Windows 上的实际运行确认了这些问题。用户希望不带参数启动即进入全屏终端界面，自动检查登录、默认开始监听，并在界面内直接查看和操作任务。

## What Changes

- 不带参数且在交互终端中启动时，进入全屏 TUI：依次检查执行实例、登录状态和下载目录，缺失时在界面内引导浏览器授权或填写目录，然后启动执行器与剪贴板监听。非交互终端仍打印帮助。
- 主面板按分享分组列出文件状态，显示彩色状态图标、进度条、速度、剩余时间、云盘与本地空间、最近事件；未完成分享展开，已完成分享折叠。
- 面板内可重试、取消（需确认）、暂停/继续整个队列、查看文件详情与错误建议、打开下载目录、粘贴分享文本、修改设置。
- 执行器支持打断当前步骤；面板操作经命令队列与执行器串行化，因此取消可以在运行中完成。新增持久化的用户暂停，与现有系统暂停分开记录。
- 剪贴板监听可在设置中关闭；新增手动粘贴输入，解析规则与剪贴板相同。
- 设置继续保存在任务库 `config` 表（已记住下载目录），新增剪贴板监听开关和用户暂停标记。
- 纯文本 `watch` 保留，进度输出改为每跨 10% 或每 30 秒最多一行。
- 所有子命令（`login`、`logout`、`status`、`retry`、`cancel`、`config`、`watch`）保留语义，供脚本与非交互场景使用。

不包含：多连接分段下载、鼠标操作、主题自定义、Linux 发行、后台服务或开机启动、多账号切换、在 TUI 中输入账号密码。

## Capabilities

### New Capabilities

- `terminal-ui`: 全屏交互界面的启动检查、任务面板、进度展示、面板操作、设置页、颜色与终端恢复。

### Modified Capabilities

- `cli-runtime`: 前台运行入口从仅 `watch` 扩展为 TUI 或 `watch`；纯文本进度限频。
- `clipboard-intake`: 剪贴板监听可关闭；新增手动粘贴输入。
- `transfer-queue`: 新增用户暂停；取消可在执行期间经串行化完成。

## Impact

- 依赖 `add-clipboard-download-workflow`：该变更归档后本变更才能归档；本变更修改其中的 `cli-runtime`、`clipboard-intake`、`transfer-queue` 需求。
- 按用户选型引入 Ink（React 终端渲染）及其依赖，这是项目首批运行时依赖。实施第一步验证 Ink 在 `bun build --compile` 下四个目标的产物、Windows Terminal、传统控制台与 macOS 终端中的原始按键、粘贴、缩放、备用屏幕和中文对齐；不通过则回到方案评审。
- 修改 `src/cli.ts` 入口、`src/runtime/`（执行器中断、命令队列、事件）、`src/state/store.ts`（只读列表查询、新配置键）；新增 `src/tui/`。
- 文件名只显示在本机界面，不写入日志或命令输出文件；凭据与提取码仍不显示。
- 发行产物体积增加；任务库结构不变，仅新增 `config` 键，无需迁移。

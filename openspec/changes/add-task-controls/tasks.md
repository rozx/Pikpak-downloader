# Tasks

按依赖顺序执行。来源：用户 2026-10-15 实测全屏界面后的反馈。复合任务只有实现与验收全部满足才勾选。

## 1. Immediate Commands

- [x] 1.1 会话命令分为中断类与立即类：`pauseQueue`，以及目标是当前串行步骤所处理文件或分享的 `cancel`、`pauseTask` 走现有队列并先中断步骤；其余命令进入串行 Promise 链立即执行，下载池中的目标先用 `engine.stopActive` 停下。验收：会话测试证明一个步骤运行期间，设置、粘贴、恢复、重试和针对非当前项的取消立即生效且不中断步骤；暂停队列与取消当前项仍先中断步骤再写入，且写入前不会开始新步骤。
- [x] 1.2 `FileWorkspace.open` 在打开根目录期间若分享被迁移到新目录，就按新目录重新打开，再写入根目录身份。验收：测试在打开过程中迁移分享，结果的根目录身份属于新目录。

## 2. Per-task Pause

- [x] 2.1 任务库结构升到 5：`files.paused`、`shares.paused`；Store 提供暂停与继续（文件、分享）、全部开始（清除全部单项暂停），`nextFile` 与 `nextScan` 跳过暂停项，`fileViews`、`shareViews` 返回暂停状态。验收：迁移测试（4 → 5 先备份、失败回滚）；状态测试覆盖暂停文件、暂停分享、继续分享清除文件标记、已完成文件忽略暂停、调度跳过暂停项、取消标记不受全部开始影响。
- [x] 2.2 会话命令 `pauseTask`、`resumeTask`、`startAll`：暂停先停下目标（下载池或串行步骤），全部开始清除队列暂停与全部单项暂停并唤醒调度。验收：会话测试覆盖暂停在途文件后其他文件继续、暂停分享停止其在途文件、继续后恢复下载、全部开始、重启后保持暂停。
- [x] 2.3 界面：`p` 暂停或继续此项、`P` 全部暂停或全部开始，提示随状态变化（为在 100 列内放下全部按键，单项提示写作“p 暂停”“p 继续”，全部提示写作“P 全部暂停”“P 全部开始”）；暂停项显示“⏸ 已暂停”，分享行显示“· 已暂停”。验收：帧测试覆盖按键命令、提示文字与暂停显示。

## 3. Manual Cloud Release

- [x] 3.1 Store 与 SpaceManager：查询文件的合格副本（本工具创建、有证据、保留中、文件不在执行中）；在云端操作锁内核对、静默删除并核对结果；服务端拒绝时恢复保留中并记录被拒绝的结果；未完成文件删除后改回就绪、保留断点。验收：模拟服务测试覆盖已完成文件释放、暂停中文件释放后继续时重新转存并从断点完成、权限被拒绝时副本保留且账号不暂停、正在执行的文件被拒绝、非本工具创建的副本被拒绝；自动回收与手动释放不会同时删除同一副本。
- [x] 3.2 会话命令 `releaseCopy`（文件或分享）与界面 `x`：命令立即返回，删除与核对在后台进行；确认框说明永久删除与重新转存的后果；事件区报告释放数量与空间或拒绝原因；释放后刷新云盘容量。为在 100 列内放下全部按键，主面板提示去掉“↑↓ 选择”，加入“x 释放”。验收：帧测试覆盖确认框（已完成与未完成两种文字）、无合格副本时的说明、确认后的命令。

## 4. Task Location

- [x] 4.1 Store 提供已完成文件的交付目标路径；`LiveController` 随本地空间刷新（每 10 秒，以及文件完成时）只读检查这些路径是否存在，结果放进快照。验收：控制器测试覆盖存在、删除后变为缺失、其他错误保留上次结果。
- [x] 4.2 视图模型计算每个文件的位置与分享的云端、本地缺失计数；分享标题与文件名前显示一个位置图标：▣ 只在本地（只有部分数据时为灰色）、⧉ 两处都有、☁ 只在云端、留空都不在，名称上下对齐；本地文件已不在时状态写明；分享计数追加本地缺失；详情页增加“本地文件”一行并改写“云端副本”的文字。验收：视图模型测试覆盖各种组合；帧测试覆盖各种位置组合、名称对齐、释放后的变化、分享计数与详情页；100 列窗口下按键提示仍完整。
- [x] 4.3 释放后删除已完成任务的记录（决策 7）：Store 判断可删除的文件（已完成、副本都已删除、无未核对操作）并按依赖删除；分享的文件都删除且扫描完成后删除分享并回收访问资料；`x` 对云盘中已没有副本的已完成文件只删记录；事件先报告再删除；详情页的文件被删除时回到主面板。验收：Store 测试覆盖可删除条件、文件与分享删除；引擎测试覆盖释放后删除、自动回收过的文件只删记录、整个分享删除并回收访问资料、本地文件保留；帧测试覆盖“删除任务记录”确认框、混合说明、行消失与详情页返回。
- [x] 4.4 按本地下载目录分组（决策 8）：列表先显示分组行（“━━ <目录> ━━  N 个分享”），再显示缩进一级的分享；分享行不再显示目录；分组行不可选中，上下移动与翻页跳过它，选中组内第一个分享时目录行一起可见。验收：视图模型测试覆盖分组顺序与可选性；帧测试覆盖两个目录的分组、目录只显示一次、上下移动跳过分组行。

## 5. Layout and Bulk Release

- [x] 5.1 任务名称去掉文件后缀（决策 9）：新分享的任务目录用任务名称、重名时写作“名称 (2)”，界面显示任务名称；临时文件放在目标旁边（“<文件名>.pikpak-part”），不再建 `.pikpak-staging`，旧计划照常完成。验收：名称测试覆盖普通、分卷、双后缀与数字点；工作区测试覆盖任务目录名、重名编号、临时文件位置与不建暂存目录；原有工作区与发布测试通过。
- [x] 5.2 全部释放与“释放中”（决策 10）：会话命令 `releaseAll` 与界面 `X`，只处理已完成任务；正在释放的文件显示“♻ 释放中”，分享行显示释放中数量；按键提示改为“x/X 释放/全部”。验收：引擎测试覆盖全部释放、排除未完成任务、释放期间的释放中集合；会话、视图模型与帧测试覆盖命令、事件文字、确认框与释放中显示。

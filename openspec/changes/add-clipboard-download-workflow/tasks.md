- [x] 2.2 使用 `bun:sqlite` 建立账号、固定目标的分享、请求版本和扫描世代、文件版本、云端副本、本地交付和操作意图记录及结构版本管理。验收：事务/唯一约束测试覆盖重复接收、持久重试预算、取消标记、未提交结果及超出 JS 安全整数范围的值；禁止 async 事务回调，重启不丢失已确认接收的工作。
- [x] 2.3 实现任务库单实例互斥及写命令冲突处理。验收：两个进程不能同时执行同一队列，第二进程得到明确提示；活动实例的状态仍能只读查询，异常退出不会留下永久占用的假锁。
- [x] 2.4 实现文件级状态与分享聚合结果、暂停原因及显式重试转换。验收：状态转换测试覆盖部分成功、自动重试耗尽、全局暂停与条件未满足的恢复，并与 `transfer-queue` 规格对应。

## 3. Account Sessions

- [x] 3.1 按 G1 结果实现独立登录及必要交互，浏览器路径不可用时使用已验证的密码路径。验收：登录契约测试与一次真实登录均返回服务端身份，密码输入不回显且不出现在参数、日志或普通文件中。
- [ ] 3.2 通过已验证的 `Bun.secrets` 或必要的原生适配实现两平台受保护存储、分享访问资料引用、串行令牌刷新和登出，Windows 验证采用本机持久化。验收：不能用类型断言代替运行时对持久化选项的验证；保存失败或超出长度限制不会退回明文；独立产物能访问本应用凭据；刷新、登出及同账号重新登录保持任务可恢复。
- [x] 3.3 实现权限拒绝、刷新失败及账号不匹配处理。验收：故障测试证明另一账号不能执行旧任务或删除旧副本，认证暂停期间不再提交云端写入。
- [x] 3.4 实现不可变分享资料引用及先保存秘密、后提交任务引用的流程，核对无引用资料后再回收。验收：分别在秘密保存前后和数据库提交前后注入失败，已确认任务不丢访问资料，失败更新不覆盖原有效资料，旧扫描持有的资料不会被提前清除。
- [ ] 3.5 编写登录与重新授权说明。验收：从干净配置按说明完成登录，并能按提示处理需用户验证、权限不足、受保护存储不可用和任务访问资料丢失的情况。

## 4. Intake and Discovery

- [x] 4.1 实现已验证分享格式的文本解析和规范化，保留精确主机/路径检查。验收：解析测试覆盖完整文本、无码分享、错误/缺失码、单独复制的码、多链接明确配对、歧义配对、相似域名和非分享内容；不跨复制事件猜测关联。
- [ ] 4.2 实现两平台稳定快照读取、变化标识去重、启动时单次接收和故障退避。验收：在读标识与读文本之间注入内容变化，系统不混配快照；相同文本重复制可触发请求，快速覆盖的漏读内容不能被虚报接收，普通剪贴板内容不落盘。
- [x] 4.3 实现分享请求事务接收、固定输出根、版本化资料补充及按请求版本合并重扫。验收：用可控交错覆盖旧扫描结束前后补码、错误返回及进程重启，新请求不被清除；待扫描时更改配置不改变已接收分享目标，持久化失败不显示已接收成功。
- [x] 4.4 实现多页与嵌套枚举、扫描世代及可靠文件版本去重。验收：契约测试覆盖分页循环、扫描中断、新增/更新/同大小替换/改名/远端移除及本地成果缺失，结果符合 `transfer-queue` 的增量规则。
- [x] 4.5 文档说明支持的分享文本、缺码补充、主动重复制触发更新和失败项显式重试。验收：示例在解析测试中可运行，解释接收确认及未确认时重新复制；不将监听描述为历史剪贴板队列或后台定时监视分享更新。

## 5. Transfer and Local Delivery

- [x] 5.1 实现按文件选择、目标磁盘预检、转存意图及 G2 确认的结果映射。验收：嵌套单文件转存契约测试不包含整个父目录，已有同名文件无法取得本工具所有权。
- [x] 5.2 实现异步转存等待、结果未知核对及超时处理。验收：在请求已受理但响应丢失时重启，不重复提交；无法唯一确认时进入需人工处理状态，不猜测副本。
- [x] 5.3 实现单连接下载、版本绑定的临时文件、持久化前缀检查点、有限重试、URL 刷新和 Range 续传。验收：覆盖正确 206、忽略范围的 200、错误范围、截断、过期 URL、远端版本变化和本地临时前缀被改动；仅使用可核对的检查点，不能拼接损坏内容或无限重试。
- [x] 5.4 实现 G3 定义的校验、本地摘要和交付提交次序。验收：校验失败不赋予清理资格；覆盖目标冲突改名后的每次意图提交、正式发布及完成记录前的中断，恢复使用最新路径和文件身份，不能误认相同摘要的用户已有文件或重复发布。
- [ ] 5.5 实现稳定分享目录、跨平台名称映射、同名后缀和不覆盖发布。验收：测试覆盖新版本同名、重试复用目标、发布竞态、大小写冲突、保留名称、长路径、路径穿越及符号链接/目录联接，不写出根目录或覆盖已有文件。
- [x] 5.6 实现按阶段选择原分享或已保存副本的恢复逻辑，以及确定副本丢失时的有界重新转存。验收：覆盖原分享失效但副本可用、副本消失而原版本仍在、原版本已更新、权限失败和结果未知；既不无故放弃可用副本，也不拼接新旧版本或重复未知转存。
- [x] 5.7 文档说明固定分享目录、版本保留、续传、原分享失效后的恢复边界及实际校验方式。验收：一次单文件端到端运行生成可核对完成记录，说明不把只有本地摘要描述为已验证远端摘要。

## 6. Cloud Capacity and Reclamation

- [x] 6.1 实现容量计划、单文件超过总容量判断和等待空间调度。验收：场景测试覆盖首次云盘已满、无合法候选、只有失败副本、其他较小文件可继续及全部等待；不得徒劳删除或忙循环。
- [x] 6.2 实现回收候选筛选、完成时间排序和操作前复核。验收：候选测试覆盖非本工具文件、未完成或已取消但未交付版本、未知归属、共享副本仍有未交付引用、远端已变化/移动及本地成果后来被删除；最后一种仍保留资格，其他不合法候选被排除。
- [x] 6.3 实现精确 ID 永久删除、操作意图与删除后容量核对。验收：失败注入覆盖响应丢失、权限拒绝、对象已不存在及容量延迟更新；无全局清空回收站或递归删除目录调用，容量足够后停止删除。
- [x] 6.4 完成可用容量小于分享总大小的集成场景，记录回收策略和空间阻塞处理说明。验收：多文件经转存、下载、按需回收循环完成，本地成果全部保留，失败文件云端副本不被自动清理。

## 7. Terminal Workflow

- [x] 7.1 集成 `watch --output`、配置持久化、目标固定规则和启动校验。验收：缺登录/缺目录时给出可操作提示，修改默认目录只影响新分享，已有分享增量文件保留原目标，暂停执行时有效输入仍能持久化。
- [x] 7.2 实现 `status`、`retry` 和前台进度汇总。验收：部分失败分享显示准确计数，用户停下监听后可以重试失败项，再启动继续，成功版本不重下。
- [x] 7.3 集成错误分类、全局暂停及条件恢复。验收：模拟认证失效、本地磁盘不足、数据库不可写、流量配额不足、限流和网络故障，均进入设计指定路径，只有云端存储不足可以触发回收。
- [x] 7.4 实现 Ctrl+C 有界退出和启动核对顺序。验收：中断后先核对未知云端操作及未完成交付，再启动新工作；不注册常驻服务或开机启动项。
- [x] 7.5 实现停下监听后的 `cancel <任务ID>`、分享/文件取消标记及 `retry` 恢复，按实际任务核对并解除无效目标导致的暂停。验收：取消不可恢复磁盘上的任务后其他任务可继续，旧剪贴板不能重启已取消分享；取消不删除文件、不清理未交付副本、不丢弃未知外部操作或撤销已发生交付。
- [x] 7.6 编写 macOS/Windows 快速开始、失败恢复及清理行为说明。验收：用户可按文档完成登录、配置、复制文本、查询失败、重试、取消及退出；明确取消保留残留资源，本地交付后由用户管理，旧云端副本仍可回收。

# 本机状态与恢复

默认状态目录为 macOS 的 `~/Library/Application Support/PikpakDownloader`，Windows 的 `%LOCALAPPDATA%\PikpakDownloader`，或 Linux 的 `$XDG_DATA_HOME/PikpakDownloader`（未设置时为 `~/.local/share/PikpakDownloader`）。`PIKPAK_DOWNLOADER_STATE_DIR` 可以为本地测试指定其他目录；同一任务库路径必须保持一个写实例。认证凭据属于当前系统用户的本应用，首版不要同时用不同状态目录运行多个执行器。下载文件放在分享接收时固定的输出目录中，任务库不跟随下载目录移动。

`tasks.sqlite` 保存账号 ID、资料引用、固定输出根、扫描世代、文件版本、转存/删除/发布意图与交付记录。密码、令牌、提取码、原始剪贴板和签名 URL 不进入任务库。凭据由系统受保护存储持有；备份数据库本身不能代替凭据备份或重新授权。

结构版本使用 SQLite `user_version`，另有应用标识校验。程序拒绝写入较新结构或其他应用数据库。当前版本为 5，包含扫描进度、目录身份、发布路径映射、分段下载检查点与暂停标记；支持从开发期版本 1–4 迁移。迁移在持有写锁、停止执行时先生成带恢复核对标记的一致性备份，再事务升级，不做自动降级。

备份功能生成带 `backup_review_required` 标记的私有一致性快照，不覆盖已有文件。可使用只读 SQLite 工具检查旧结构快照，不能直接作为活动队列执行；当前 CLI 的状态查询使用当前结构。旧备份可能遗漏之后发生的转存、发布或永久删除；恢复必须先核对未知远端操作、本地文件身份及已发生的交付，再由受控恢复流程开启写入。首版不提供自动恢复旧备份后立即继续的命令。

丢失任务库后，云端同名文件、相同内容或已有目录都不能自动取得本工具归属。重新安装不会凭名字接管或删除它们。本地历史完成记录也不能仅靠扫描目录重建；本工具不是备份修复或目录同步工具。

SQLite 使用 WAL、`synchronous=FULL`、外键和短同步事务。网络与凭据操作不能进入事务回调。数据大小使用十进制字符串存储并转为 `bigint`，请求版本及重试计数采用精确整数。

运行互斥采用单独的 `queue-lock.sqlite`：实例持有其 EXCLUSIVE 事务所用的系统文件锁，退出或崩溃后由系统释放。它不根据文件是否存在判断占用，也不在任务库持有长事务，因此活动队列仍可由 `status` 只读查询。跨进程占用、修改冲突和强制退出后重获锁由测试在 macOS、Windows 与 Linux 上覆盖。
